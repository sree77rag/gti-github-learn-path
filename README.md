Welcome to **GTI — Git & GitHub Learn Path**, my personal space for learning and practising Git, GitHub, and the workflows used by software developers.

The goal is to understand each concept, practise commands in the terminal, verify the results, and build confidence through consistent hands-on learning.

## 05 · Essential Git Commands

### Initialise and inspect

```bash
# Check whether Git is installed
git --version

# Create a new local repository
git init

# Check the working tree
git status

# Inspect unstaged changes
git diff

# View recent commits
git log --oneline
```

### Stage and commit

```bash
# Stage a specific file
git add hello.py

# Stage all current changes
git add .

# Record staged changes
git commit -m "Add initial Python file"
```

### Connect and publish

```bash
# Add a GitHub repository as a remote
git remote add origin <repository-url>

# Check configured remotes
git remote -v

# Rename the current branch to main
git branch -M main

# Push the main branch to GitHub
git push -u origin main
```

**Note:** Replace `<repository-url>` with your actual GitHub repository URL. The push command assumes your current branch is named `main` after the rename. GitHub authentication and the remote repository must be configured first.
