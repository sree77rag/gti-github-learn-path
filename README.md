## 🎯 01 — The Mission

Welcome to **GTI (Git & GitHub Learn Path)**, a rigorous, hands-on learning repository dedicated to mastering modern version control workflows, collaboration protocols, and professional developer habits.

> **Core Philosophy:** True mastery comes from understanding the underlying state machine of Git, not just memorizing commands. Every module here bridges theory with real terminal execution.

---

  <img src="https://skillicons.dev/icons?i=git,github,ubuntu,bash,py,vscode&theme=light" alt="Git, GitHub, Ubuntu, Bash, Python and VS Code"/>

| Technology | Role in Workflow |
| :--- | :--- |
| **Git** | Distributed version control & history tracking engine |
| **GitHub** | Cloud hosting, remote collaboration, & code review hub |
| **Ubuntu Linux** | Primary Unix-based development environment |
| **Bash** | Terminal automation & command execution |
| **Python** | Sandbox language used for tracking file changes |
| **VS Code** | Modern source code editor & git integration interface |
